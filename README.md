# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

写清炒文书必须挂靠一条**未使用**的蒸汽压力记录：炮制员先在蒸汽压力台按锅次登记读数与读取时刻，再在总表选一条未使用记录写入；无挂靠或重复挂靠一律拒写。挂靠成功后压力记录标记已用，压力原文（锅次、读数、读取时刻）冻结进文书 `doc.pressure`，之后不随压力台账变化。压力登记限炮制员，质检员可查压力台但不能登记。顶栏「蒸汽压力链」是独立落地页，含压力登记、未使用列表、已挂靠文书一览。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 蒸汽压力挂靠：
   - processor 在顶栏「蒸汽压力链」登记一条压力（锅次、读数原文、读取时刻），出现在「未使用压力记录」。
   - 回总表写甘草并选择该压力记录：成功放行，该记录从压力台未使用列表消失、进入「已挂靠文书一览」，总表该行显示冻结的压力原文。
   - 不选择压力记录直接写入：拒写（提示先登记并选择压力记录）。
   - 同一条压力记录不能挂靠第二条文书：重复使用返回 400。
   - checker 打开蒸汽压力链可查看全部记录，但没有登记表单；调用登记接口返回 403。
