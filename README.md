# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

写入清炒必须挂靠一条未使用的蒸汽压力记录：炮制员先在「蒸汽压力」页登记锅次的压力读数与读取时刻，写文书时选一条未使用记录挂靠；挂靠后该记录标记已用，压力原文随文书整包冻结。质检员能看压力台，不能登记。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 不挂压力记录直接写清炒，接口拒写（必须挂靠一条未使用的蒸汽压力记录）。
3. 顶栏进「蒸汽压力」页登记一条压力，回总表选该记录挂靠写甘草，成功放行；该压力记录随即标记已用，出现在「已挂靠文书一览」，压力原文冻结在文书里。
4. 同一压力记录再次挂靠被拒；另登记一条后写温度 200 的清炒，结论仍是未放行。
5. checker 能打开「蒸汽压力」页看压力台，但没有登记入口，也看不到写入按钮。
